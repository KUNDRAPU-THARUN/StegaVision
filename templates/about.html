Purpose

1. Project Objective

StegaVision provides an interactive way to study how text can be embedded in digital images, how embedding affects image quality, and what basic pixel statistics reveal. It is intended for learning and demonstration, not for cryptographic protection.

Spatial domain

2. LSB Steganography

Least Significant Bit embedding changes the lowest-order bit of selected pixel-channel values. This can represent message bits with small numerical pixel changes, while capacity depends on the number of usable channels and the payload header.

Frequency domain

3. DCT Steganography

The image is processed in 8×8 blocks. A Discrete Cosine Transform expresses each block in frequency coefficients, and selected mid-frequency coefficients are adjusted to encode bits while avoiding the DC component.

Image quality

4. Image Quality Metrics

Mean Squared Error (MSE) measures average squared pixel difference. Peak Signal-to-Noise Ratio (PSNR) expresses error relative to the pixel range, and Structural Similarity (SSIM) compares local luminance, contrast and structure.

Image inspection

5. Image Analysis

Image analysis reports dimensions, format and channel histograms, and visualizes the least significant bit plane from the actual uploaded pixels.

Statistical observations

6. Basic Steganalysis

Basic steganalysis summarizes LSB balance and per-channel pixel statistics. These measurements are descriptive and can be affected by image content, processing and compression.

Scope

7. Limitations

Steganography is not encryption. The methods demonstrated here do not guarantee confidentiality, invisibility or resistance to transformations. Statistical observations alone cannot establish that an image contains hidden data.
